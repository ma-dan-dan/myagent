2. 修复 Agent Loop 预算
- 当前 max_rounds=2 与 max_tool_calls=2：连续两次 Tool 调用会耗尽两次模型调用，无法再让模型根据 Tool 结果生成最终回复。

- 将“模型调用次数上限”和“Tool 调用次数上限”拆成语义明确的配置，或者采用同等清晰且可验证的设计。
- 增加测试：模型先调用 Tool、再得到最终回复时必须成功；超限时必须返回稳定错误，且不会继续执行 Tool。
